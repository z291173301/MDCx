                        …  Xcity                    ← 标题之下是一份去重后的 A-Z 名单

                          或整组加入，名单取自上面七组默认名单同一个常量 TYPE_DEFAULT_SITES，

    站点悬停提示    只有一行，分隔符一律「/」（不用顿号，省宽度）：
                        <定位>：<类型名单>      7mmtv→「综合：有码/无码/欧美/传媒」

                    个摄（即原来的 FC2 组）同属有码那一类、只是没番号。「短剧」照常显示（它只有 JavDay

                    第一行已经把类型名单说全，后两行是同一件事的重复，还把悬停框撑成三行。
                    原本第一行的值还是爬虫 description 里写死的文案（「综合：有码+无码+FC2」），
                    会与实际默认名单对不上（7mmtv 明明也在欧美、传媒名单里）；不属任何类型组

                    名单只有一项时，这一行冒号后可改用该站的别称（_CAPTION_TYPE_ALIAS），
                    如 Madou.club 只有国产，重复一遍不如写厂牌别称「国产：麻豆」。
                    这一行同时也是**三个站点下拉**（刮削网站页「指定网站」、网络页「当前网站」
                    「不走代理的网站」）选项显示文本里那段文案，与那个弹窗同源、不会各写一份；
                    下拉框自己的悬停提示按用户要求只保留「上次检测：…」，不再重复能力文案。
    分组标题        七个标题各占普通的一格，排在一行里的最前面，后面**不留空白**（第一个站
                    紧接在「动漫」右边），与其它站点一样的白底、**只有文字加粗**，不额外
                    加深底色，也不会被「聚焦框」圈起来（候选区、启用网站列表、字段优先级窗口
                    下方每一行，这三个列表都没有当前项：Qt 默认会把第一行设成当前项、聚焦时
                    又会重新选中第一行，候选区里那正好是第一个标题；而用户在列表里
                    点一个站点只是要选中它，并不想让 Qt 再在它内侧套一圈「聚焦框」）。
                    标题不可选中、不可拖动、不带 UserRole，所以不会被当成站点混进「启用网站」
                    或复制结果。**双击**某个标题 = 把该组全部网站加入「启用网站」（联动组自动
                    补齐）；单击什么也不加——七个标题挤在首行，顺手扫过必然挨个碰过去，
                    一点就整组塞进去且无从撤销不是用户要的。名单挂在标题自己身上
                    （SITE_GROUP_ROLE 记标题、SITE_GROUP_SITES_ROLE 记该组成员），所以点
                    哪个标题就是哪一份名单，不会把末尾零散站点算进上一组。
                    站点行的单击只是选中，加入靠双击站点或「添加选中」。
    右键            点站点 → 复制该站名；点标题 → 复制该组名单（如「有码」28 站、「个摄」12 站，
                    互不相等）；点空白处 → 复制整张列表（逗号分隔，与对话框上方输入框同格式，
                    可直接粘回）。候选区的右键菜单**最下方**另有「加入列表：启用网站」：
                    点标题加入整组、点站点加入那一个、点空白处加入当前选中的那些
                    （与双击同一套 `_add_sites`，已启用的保持原位、联动组自动补齐）。
                    「启用网站」列表与「字段优先级」那几行没有这一项——那里没有「启用列表」
                    可言，点了只会让人不知道加到哪儿去。
                    站点右键菜单最上方另有「启用站点：X」「禁用站点：X」两条（在「复制站点」之上，
                    两条始终显示、按当前状态互斥置灰）。禁用状态存在全局 website_disabled，
                    七个类型组共用：任一组的候选区或启用列表里禁用，其余组同步变灰；
                    默认空列表即全部启用，每次启用/禁用立即落盘，无需再点「保存」，
                    点「取消」也不会回滚。被禁用的站仍可选中、拖拽、
                    移除，网络检测不再生成检测项，自动刮削的完整/极速路径与强制单站路由都在
                    请求前跳过，DMM/MGStage 图片兜底也不再把它们拉回来；但用户明确指定该站时
                    （指定网站模式、单文件、重新刮削）不受禁用影响，仍会正常请求。重新启用即
                    恢复原优先级。
    启用网站列表    顺序完全由用户拖拽决定，与候选区分组无关；「全部添加」写入的仍是
                    爬虫注册序，不受分组影响。
