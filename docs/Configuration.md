# 配置参考

每个配置项是干什么用的。按功能分组说明，各组内容与设置页标签的对应关系如下：

| 文档分组 | 设置页标签 |
|---------|-----------|
| 通用 | 刮削目录 |
| 清理 | 刮削目录 →「清理文件」区 |
| 刮削 | 刮削模式 + 刮削网站 |
| 字段优先级 | 刮削网站 → 各类型旁「字段优先级」按钮 |
| 翻译 | 翻译 |
| 下载 | 下载（海报、缩略图、背景图、额外剧照/预告片、NFO 分别在该页分组内；下方「字幕」「水印」「NFO」章节的详细选项在设置页同名字幕、水印、NFO 标签页） |
| 字幕 | 字幕 |
| 水印 | 水印 |
| 命名 | 命名 |
| 服务器（Emby/Jellyfin） | 左侧导航「演员管理」页 |
| 网络 | 网络 |
| 界面外观（缩放、调试模式） | 高级 |
| 其他（更新检查、演员数据库） | 高级 + 演员 |

## 通用

| 配置项 | 作用 |
|-------|------|
| 待刮削视频目录 | 放视频文件的目录（配置字段名 `media_path`） |
| 成功输出目录 | 刮完后把文件复制一份到另一个地方，不填就不复制 |
| 失败输出目录 | 刮失败的文件挪到这个目录 |
| 软链接路径 | 创建软链接的目标目录（不移动原文件） |
| 媒体类型 | 视频文件扩展名，默认 mp4/mkv/avi 等 |
| 字幕类型 | 字幕文件扩展名，默认 srt/ass 等 |
| 跳过小文件 | 小于指定大小的文件不处理 |
| 跳过成功文件 | 已经刮成功的文件跳过不处理 |
| 记录成功文件 | 把成功记录写到文件 |
| 使用软链接 | 不移动原文件，创建软链接 |
| 符号链接定义 | 硬链接相关配置 |

## 清理

| 配置项 | 作用 |
|-------|------|
| 清理指定后缀 | 删除某些后缀的文件 |
| 清理指定文件名 | 删除名字包含指定字符串的文件 |
| 清理包含字符 | 删除文件名里含指定字符串的文件 |
| 清理小于指定大小 | 删除小于某个值的文件 |
| 忽略指定后缀 | 上述清理不碰这些后缀 |
| 忽略包含字符 | 上述清理跳过名字含指定字符串的文件 |
| 自动清理 | 刮完后自动执行清理 |

## 刮削

| 配置项 | 作用 |
|-------|------|
| 并发数 | 同时刮多少个文件（建议 3-5） |
| 间歇模式 | 每刮完一批停一会儿，防止被网站封 |
| 工作模式 | 设置→刮削模式：正常模式 / 整理模式 / 分离模式 / 视频模式 / 更新模式 / 读取模式 |
| 整理模式间隔 | 设置→高级→高级功能下「任务模式」两枚互斥选项：本地存储文件（默认，整理模式不设置时间间隔整理文件）/ 网盘存储文件（整理模式按「设置→高级→间歇刮削→自动休息」设定的间隔整理文件，两次整理之间至少间隔自动休息时间） |
| 网站偏好 | 设置→刮削网站：字段优先 / 速度优先 / 指定网站（配置字段 `scrape_like`：info / speed / single） |
| 读取模式 | 读取模式的 4 个子选项 |
| 更新模式 | 更新模式的目标文件命名模板 |
| 文件移动 | 成功后移动/重命名，失败移动文件 |

## 高级功能

设置 → 高级 → 高级功能：
- 隐藏信息管理：隐藏界面中的信息管理选项
- 导入账单：绑定本机 CPU 编号后导入捐助账单（未绑定机器按钮不显示）
- 设备编号：导出本机设备编号 txt 文件（用于申请授权）
- 任务模式：本地存储文件 / 网盘存储文件
- 调试模式：开启后显示更多调试信息
- 自动休息：间歇刮削时的自动休息时间

## 授权与绑定

本项目已改名 MDCx-Dev 并私有开发仓。公开仓库 MDCx 仅用于发布版本和同步文档。发版流程：
1. 私有仓 MDCx-Dev 运行构建工作流（build-py315.yml）
2. 构建成功后直接发布到公开仓库 MDCx（使用 MDCX_SOURCE_TOKEN / MDCX_SOURCE_REPO）
3. 移除原 sync-public-release / mirror-release.yml 依赖
4. 公开仓库的 Action 使用私有仓源代码构建并直接发版
