# 使用手册

日常使用 MDCx 会遇到的各种操作和问题。

## 界面说明

软件界面分成几块：

- **顶部**：工具栏（开始、停止、播放等按钮）
- **左侧**：导航栏（软件界面、软件日志、软件工具、演员管理、信息管理、软件设置、检测网络、使用说明）
- **中间**：主工作区（待刮列表、刮削结果树「成功/失败」、封面预览）
- **底部**：进度条和状态信息

设置界面通过左侧导航「软件设置」进入，分为 12 个标签页（刮削目录、刮削模式、刮削网站、下载、命名、翻译、字幕、水印、NFO、演员、网络、高级）。网站的连通性与可用状态在左侧导航「检测网络」页查看。

## NFO 文件管理

左侧导航「信息管理」页面用于浏览和批量编辑已刮削的 NFO 文件。

1. 点击「选择目录」或手动输入目录后回车，自动递归扫描生成文件列表
2. 顶部筛选框支持按番号/演员/标题关键词过滤列表
3. 点列表项读取 NFO，中栏表单可编辑番号、标题、演员、发行日、导演、制作商、系列、评分、简介、标签等 15 个字段
4. 右栏同步预览本地海报和缩略图，「裁剪封面」可调起裁剪工具
5. 点击「保存当前 NFO」时自动对比改动并弹窗确认（字段级 diff），无改动不写盘
6. 批量操作面板：列表顶部「全选/全不选」或 Ctrl+点击勾选多条后，一键替换演员名、加标签、删标签、统一系列
7. 列表右键菜单：重新刮削番号（找同目录同名视频入队）、打开所在目录、删除 NFO 文件

## 基本操作流程

### 1. 配置刮削目录

设置 → 刮削目录：
- **待刮削视频目录**：放视频文件的文件夹
- **成功输出目录**：（可选）处理好后复制一份到另一个地方
- **软链接路径**：（可选）创建软链接的目标目录

### 2. 选网站源

设置 → 刮削网站：
- 按影片类型分别配置：有码番号、无码番号、个摄番号、欧美视频、国产传媒、国产短剧、动漫里番
- 每个类型可以选多个网站，拖动排序决定优先级
- **免 CF 通道**（JavDB_API、JavDB_APP、Missav_API、R18.dev、TheJavDB）默认已加入网站源，稳定性好可优先使用

### 3. 字段优先级

设置 → 刮削网站 页每个类型旁的「字段优先级」按钮：
- 每种字段（标题、简介、演员、海报等）都可以独立配置来源网站顺序，也可勾选「跳过」不从任何来源抓取
- 比如标题优先用 JavBus，评分优先用 DMM
- 每种刮削类型（有码番号、无码番号等）还可以有不同的字段优先级配置

### 4. 配置下载

设置 → 下载：
- 勾选需要下载的内容：海报、缩略图、背景图、剧照、预告片
- 人脸裁剪：开启后自动检测人脸位置裁剪海报
- Amazon 高清封面：从 Amazon 搜索高清图
- 官方图源兜底（默认开启）：图源全部失败时直构官方 CDN 高清图——DMM 高清封面（自动学习厂牌前缀）+ MGStage 素人高清海报
- JavDB 系图源自动无水印：刮削到 javdb 图床的封面/海报/剧照时自动改为 JavDB App 无水印原图（加密流透明解密，无需配置）

### 5. 翻译（可选）

设置 → 翻译：
- 选翻译引擎（Google / Bing 不需要配置，直接用）
- 选需要翻译的字段
- 可选 LLM 翻译引擎（需要配置 API Key）

### 6. 字幕、水印、命名、NFO

设置 → 字幕：配置字幕下载与内嵌规则
设置 → 水印：配置图片水印位置与内容
设置 → 命名：配置文件重命名规则
设置 → NFO：配置 NFO 写入规则与字段映射

### 7. 网络代理

设置 → 网络：
- 配置 HTTP/HTTPS/SOCKS5 代理
- 测试站点连通性
- 代理分流：可选「全部走代理」或「交给 Clash 类软件裁决」

### 8. 高级设置

设置 → 高级：
- 界面外观：缩放、主题、字体大小
- 调试模式：开启后显示更多调试信息
- 更新检查：自动检查新版本
- 任务模式：本地存储文件 / 网盘存储文件
- 隐藏信息管理、导入账单、设备编号等高级功能

## 常见问题

- 界面显示异常：检查缩放设置，重启程序
- 刮削速度慢：减少并发数，检查网络连通性
- 站点无法访问：检查代理设置，使用「检测网络」页测试
- 图片无法下载：检查网络代理，确认图源可访问
- 授权问题：检查设备绑定状态，确认授权文件有效
